Design System
Guardian Shield · Design System · V3

“Watchtower” — the Guardian Shield design language

Direction. A serious consumer-security product used in private moments: late-night browsing, recovery from relapse, family protection. The visual voice is calm vigilance — a deep charcoal night with one luminous signal color, Beacon Mint, that means “your guardian is awake.” Green is the natural security primitive (browser padlocks, antivirus “you are protected”), and it semantically fuses brand with the app’s core state: protected. Chrome stays near-monochrome; color is used only for meaning — mint = protected/interactive, red = blocked, amber = warning, violet = AI. Elevation is real and layered (tonal steps + diffused shadows + hairline + top light-seam), replacing v2.5’s flat bordered cards. Typography is a deliberate Roboto Flex scale with tabular numerals for every stat; Bengali set in Noto Sans Bengali at matched weights.

Why dark-first (reasoned choice): block overlays and warnings overwhelmingly appear at night or in bed; OLED dark reduces glare in those moments; the strike-3 overlay must dominate any host app (dark scrim); and privacy-screening in public. Light theme is explicitly out of scope for V3 (flagged, not silently skipped).

What this replaces: v2.5.0’s blue-graphite palette (#0E1116 / periwinkle #D0E4FF), flat 0-elevation bordered cards, emoji row icons, mixed radii. Nothing about detection/blocking logic changes — visual language only.

Scrim fade + hero scale 0.92→1 with glow bloom; content staggers 40ms. Exit only via actions.

240ms emphasized

Sheets & dialogs

Bottom sheets slide up with emphasized decelerate + scrim to 60%; dialogs fade + scale 0.9→1. Keypad error = 3-frame horizontal shake (existing anim reused).

sheet 320ms · dialog 180ms

Beacon pulse

Hero status ring breathes (opacity .35→.14, 2.4s ease-in-out, repeat with reverse) while protection is ON. Stops when paused/off.

2400ms · infinite alternate

Pull-to-refresh

M3 Circles indicator in Beacon on Activity Log (the only list with re-queryable data).

system timing

Principles: motion explains hierarchy (what came from where), never decorates. Durations ≤400ms. Easing: emphasized-decelerate for entrances, standard for exits. Nothing loops except beacon pulse & shimmer, both sub-perceptual. Respect OS reduce-animation setting (pulse/shimmer/stagger drop out).
