Decision log Dark-first (reasoned: night-time block moments, OLED, overlay dominance) · Beacon Mint primary (security’s native “protected” color; replaces periwinkle) · success shares the Beacon family by design (protected = success) · real elevation replaces flat bordered cards · sentence-case buttons, caps only for 11sp kickers · emoji removed from UI chrome (kept only in user-facing motivational/religious copy where the strings include them). What this deliberately is NOT: a Material You default demo — the beacon-ring hero, category spines, and watchtower mark give it a signature; everything else stays restrained and native.
