Guardian Shield · Design system · One UI 8

One Shield

A complete visual language for Guardian Shield, written in Samsung One UI 8 — not generic Material 3, and not the previous Watchtower mint/charcoal system. One confident Galaxy Blue on true AMOLED black. Oversized left titles that collapse on scroll. Grouped settings sheets with real gaps. Large pill switches. Controls sit where a thumb already is.

App name stays Guardian Shield. Shield mark is refined, not replaced. No mascot. Detection, strike counting, and unblock behavior are out of scope.

0 · Why this is One UI 8

not Material · not Watchtower
Recognizable traits

One UI is a one-handed reading surface. The top of the screen is for orientation — a huge left-aligned title, a status, a hero. The lower two-thirds is for work — switches, chips, primary actions. Settings are not a dense list: they are large rounded sheets with air between groups. Switches are big, pill-shaped, and fill with a single system blue. Corners are soft everywhere. Nothing is sharp. Body type stays comfortably large.

Decisions

Canvas is #000. One UI dark is true black; gray cards float on it. That is the look.
One accent. Galaxy Blue only. Watchtower’s mint, violet-for-AI, and per-category spines are retired. Red / amber are status, not brand.
Protected = switch on. Same as Samsung Settings / Device Care — the blue fill is the “on” signal. No second “success green” brand.
Light theme out of scope (flagged, not skipped).

What this is not. Not Material 3 Expressive (colorful, smaller titles, tonal layers as brand). Not Watchtower (Beacon Mint #7FE7C4, charcoal-green surfaces, category spines, violet AI). Not iOS-26 glass. One UI 8.0 is solid dark sheets; 8.5’s frost is noted but not the target — XML Views cannot honestly ship system blur, and 8.0’s solid cards are the recognizable Galaxy Settings look.

Collapsing large title. Every scrollable screen starts with a 40sp left-aligned title sitting under the status bar (One UI’s signature since 1.0). As the user scrolls, the large title fades/scales away and a 21sp compact title occupies a 56dp app bar. Non-scrolling screens (PIN, overlays) keep a static large title — they never fake a collapse.

Rules. Sentence-case buttons. Caps only on 12sp kickers. Bengali never uppercase, never tracked beyond −0.01em, line-height 1.6. Stats and countdowns use tabular figures. Typeface: Pretendard (SamsungOne stand-in) + Noto Sans Bengali.

3 · Shape

nothing sharp · sheets not tiles
xs 12 · badges, checks
sm 16 · icon wells, inputs
md 20 · inner cards
lg 28 · settings sheets
xl 32 · heroes, dialogs
pill · buttons, switches

Watchtower used 8 / 12 / 16 with hairline + light-seam elevation. One UI 8 sheets are larger and quieter — 28dp group cards, no drop shadow on resting sheets, separation by gap (16dp) not by stroke. Hairlines exist only inside a sheet, between rows. Buttons and switches are always pills.

4 · Spacing

generous · one-handed
4 · 8 · 12 · 16 · 20 · 24 · 28 · 32 · 40 · 48 · 64

Screen gutter 20dp. Gap between sheets 16dp (the One UI group gap). Sheet inner padding 4 / 0 — rows themselves pad 18–20 horizontal, 64dp min height. Section label (13sp, text-sec) sits 8dp above its sheet, 20dp below the previous sheet. Bottom nav 64dp + gesture inset. Primary actions live in the lower two-thirds; titles and hero status occupy the top. Settings search, when shown, sits just above the nav (One UI one-handed reach — not a new feature, a placement rule).

5 · Controls

large · pill · one blue fill
Buttons

52dp pill. One filled action per screen. Tonal = L3. Ghost = accent-bright text. Danger only for exit-intent on the overlay.

Switch · checkbox · chips
All 42 AI 18 Keyword On Paused Blocked PLAIN

Switch 52×32, white thumb, accent fill when on — the One UI control. Not a small Material switch.

Slider
30s

8dp track, 24dp thumb with 6dp accent ring. Used for Unlock delay and AI threshold. Value badge always visible, never tooltip-only.

Keypad key

PIN keys are 84×64, radius 20 (soft rect, not circle — One UI calculator/phone feel). OK is the single filled key.

7 · Motion

Material patterns · One UI timing

Large title collapse

Scroll 0–48dp: large 40sp title fades and scales toward the compact 21sp bar. Bar height 0→56. No snap.

220ms · ease-out (.22, 1, .36, 1)

Fade-through · tab content

Home ⇄ Protection (the only in-shell fragment swap). Out 90ms, in 210ms + 8dp up.

300ms · M3 FadeThrough

Shared-axis X · pushes

Dashboard → App List / Keywords / Schedule / Settings / Activity. Incoming from end, outgoing fades.

300ms · M3 SharedAxis · ease-out

Container transform

Activity row → Blocked Detail. Corner 28→0, shared bounds. Only this pair.

380ms · emphasized

Press

Cards, rows, keys, buttons: scale 0.98 + 4% white overlay. Release springs past 1.0 to rest.

in 140ms · out 260ms spring (.34, 1.3, .64, 1)

Switch

Thumb translates 20dp with slight overshoot; track crossfades to accent. Haptic on commit (system).

280ms · ease-spring

List entrance

Fade + 12dp up, 16ms stagger, cap 8 items. Once per appear, never on rebind.

200ms / item

Skeleton → content

Shimmer 1200ms loop on #2A↔#3A. Crossfade to content. No circular spinner anywhere.

crossfade 200ms

Strike 1/2 card

Slides from top, soft decelerate. Decorative timer ring drains in 3.5s — visual only; dismiss timing stays STRIKE_WARNING_AUTO_DISMISS_MS = 3500. Exit slides up + fade.

enter 260ms · ring 3500ms linear

Strike-3 overlay

Scrim 0→62% + sheet slides up 24dp. Content stagger 40ms. Leaves only via actions.

320ms · ease-out

Dialogs / sheets

Dialog: fade + scale 0.92→1. PIN error: existing 3-frame shake reused. Bottom sheet: slide + scrim.

dialog 180ms · sheet 320ms

Reduce motion

If OS reduce-motion is on: drop spring overshoot, shimmer, stagger, and decorative ring. Instant fade only.

respect Settings → Notifications / vision

One UI’s feel vs stock Material is the softer exit curve and a hint of elastic on controls, not longer durations. Nothing loops except skeleton shimmer. Motion explains hierarchy.
