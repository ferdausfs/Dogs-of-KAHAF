Guardian Shield · One UI 8 · v3.5.0 Phase 1c

PIN recovery — deliberately non-trivial

Two honest paths, both with real friction. Path A: the recovery code shown once at PIN setup (stored only as a salted hash — never searchable in the app). Path B: a 48-hour time-delayed reset with a persistent warning notification — same spirit as the cooling-off system. No instant “forgot PIN → reset” shortcut exists by design.

Scope: mock only — sets layout/tokens. Full gate (verify hashes, WorkManager 48h clock) lands in code in the same phase.
