Guardian Shield — Sentinel Design Language

Design Tokens — Sentinel · Guardian Shield — Design Tokens

The complete, from-scratch design language. Light-on-dark, green-graphite obsidian with a single phosphor-emerald signal color.

Why dark + emerald

A security product is always-on, always-watching: dark lowers OLED drain and distraction, and reads as vigilant. The single emerald accent is the product’s one semantic truth — "protected / all-clear" — so every green element means the same thing. Amber = warning, red = blocked/error, violet = AI, blue = info. No emoji-as-icon: one stroke-based icon family, one weight.

Iconography · আইকন
